# Markdown-to-HTML-converter

This web app takes markdown text and converts it to HTML.

Markdown HTML

# heading 1 <h1>heading 1</h1>

## heading 2 <h2>heading 2</h2>

### heading 3 <h3>heading 3</h3>

**bold text** or **bold text** <strong>bold text</strong>
_italic text_ or _italic text_ <em>italic text</em>
![alt-text](image-source) <img alt="alt-text" src="image-source">
[link text](URL) <a href="URL">link text</a>

> quote <blockquote>quote</blockquote>

I use regex to convert that text to raw text on one preview and actual HTML on the last preview.
